# Site profiles

Set up once per site, after the owner signs up and OKs the bio. The bio is a lasting backlink.

- **Display name:** "NerdIT" (or the owner's own name if they choose that at first setup; then use it
  on every site).
- **Bio (owner OKs once, then the same everywhere; trim to the site's limit):**
  "NerdIT: free online courses in AI, data science, Python and web development, by Future Vision
  Computers, India. Learn free at https://nerdit.in"
- **Website field:** https://nerdit.in
- **Profile photo:** the NerdIT logo that brand-studio uses (`brand-studio-plugin/brands/nerdit/`),
  square-cropped on a white background.
- Skip anything else (location, phone, birthday, newsletters, notifications): leave the defaults.
