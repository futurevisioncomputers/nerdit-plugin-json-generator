# hackernoon

- **Start:** https://app.hackernoon.com/new
- **Signed in when:** your avatar in the editor header
- **Kit:** Articles page -> Copy text
- **Steps:**
  1. Paste the title into the title field and the rest into the body.
- **Canonical / original URL:** Story settings: canonical link = the nerdit.in article URL.
- **Images:** Markdown image links may not render: upload each image file where its line is.
- **Publish:** Submit for review (editors check it first; it is not live yet).
- **Post URL:** After review the live URL is https://hackernoon.com/<slug>. Log `posted` with the draft URL and tell the owner to paste the live link when the review email comes.
