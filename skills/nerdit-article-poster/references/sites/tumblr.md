# tumblr

- **How:** by API from the Articles page, never in the Tumblr editor. New articles usually post by themselves
  when published; this covers articles that missed it.
- **Start:** fv.nerdit.in/articles -> the article -> Edit -> the Tumblr row
- **Signed in when:** the row says 'Connected' and shows a **Post copy** button (no button: `failed` with
  "Tumblr not connected in the admin" and a report line for the owner)
- **Kit:** none to copy: the admin sends its own copy (opening + link).
- **Steps:**
  1. Press **Post copy**. Wait ~6 s; the row then shows '✓ tumblr.com/futurevisioncomputers-blog/<id>'.
- **Canonical / original URL:** None. The copy is the opening + link.
- **Images:** None to upload.
- **Publish:** Post copy publishes it.
- **Post URL:** the row's link (https://www.tumblr.com/futurevisioncomputers-blog/<id>). Already saved on the
  Articles page; only `runlog mark ... --status posted --url <link>`.
- **Never:** press **Update copy**.
- **Verified:** yes, 2026-11-24
