# wordpress

- **Start:** https://wordpress.com/post
- **Signed in when:** the block editor opens (no login page)
- **Kit:** Articles page -> Copy text (opening + link)
- **Steps:**
  1. Paste the title into 'Add title' and the body into the first block (the editor turns markdown into blocks).
- **Canonical / original URL:** None (custom canonical needs a paid plan).
- **Images:** Markdown image lines become image blocks; check each shows, else upload the file.
- **Publish:** Publish -> Publish.
- **Post URL:** https://<site>.wordpress.com/<yyyy>/<mm>/<dd>/<slug>/
- **Verified:** no
