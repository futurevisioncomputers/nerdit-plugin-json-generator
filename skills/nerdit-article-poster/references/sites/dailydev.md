# dailydev

- **Start:** https://daily.dev/squads/nerditin (the NerdIT Squad, made 2026-11-24: public, category AI, only
  moderators post). Public Squads such as Learn Python ban self-promotion (rule 3), so share NerdIT articles only here.
- **Signed in when:** your avatar in the sidebar and the Squad's 'What's on your mind?' box
- **Kit:** title, note, tracked link: link = article URL + `?utm_source=dailydev&utm_medium=share&utm_campaign=<slug>`,
  note = the article description.
- **Steps:**
  1. 'Share a link' in the Squad's post box -> 'Paste a link...' = the tracked link (a preview card with the cover
     appears) -> 'Add a comment' = the description.
- **Canonical / original URL:** Not needed.
- **Images:** None (daily.dev shows the article's cover from its page).
- **Publish:** Post.
- **Post URL:** the new post link on the Squad page: https://daily.dev/posts/<slug-id>. The Articles page accepts it.
- **Verified:** yes, 2026-11-24
