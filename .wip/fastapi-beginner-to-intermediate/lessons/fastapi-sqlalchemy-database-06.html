1 — 🔗 Connect to a Database with SQLAlchemy

How does a Python object turn into a row a database can store? An ORM (object-relational mapper) maps a Python class to a table. You then read and write rows as plain objects, instead of writing SQL by hand. SQLAlchemy is the ORM FastAPI projects use most.

An engine is the object that knows how to reach one database. It holds the file path or server address, and the driver that speaks its language. You build it once, with create_engine(), and every later piece of code reuses it.

A mapped class inherits from DeclarativeBase, a small base class SQLAlchemy ships with. Each typed attribute on that class becomes one column, and the class itself becomes one table.

Python class → database tableclass Learner(Base)   → table learners
learner_id: Mapped[str] → column learner_id, text
age: Mapped[int]        → column age, whole number

Reach for an engine and a mapped class the moment a route's data must survive a restart. A list in memory is fine only while you are still sketching the shape of the data.

Learner(Base) — Map One Class to One Table

create_engine points at a SQLite file; DeclarativeBase turns Learner into a real table.

You type 
from sqlalchemy import create_engine, String, Integer, Float
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
engine = create_engine("sqlite:///:memory:")

class Base(DeclarativeBase):
    pass

class Learner(Base):
    __tablename__ = "learners"
    learner_id: Mapped[str] = mapped_column(String, primary_key=True)
    branch: Mapped[str] = mapped_column(String)
    age: Mapped[int] = mapped_column(Integer)
    weekly_study_hours: Mapped[float] = mapped_column(Float)

Base.metadata.create_all(engine)
print(Learner.__tablename__)

2 — 🔄 Give Each Request Its Own Session

An engine can hold many connections at once, so a route must never share one connection with another request. A Session is a short-lived workspace for one request's database work. It tracks what you add or change, then sends it.

sessionmaker(bind=engine) builds a factory that hands out a fresh Session whenever you call it. You used yield for setup and cleanup in Lesson 5. get_db is the real job that pattern was built for.

FastAPI calls get_db through Depends() for every request. It opens one Session and hands it to your route. Then it closes that once the route ends, even if the route raises an error.

One Session opens for the request and closes right after, even if the route raises an error.

🌟 Case Study: Loading Future Vision's First Two Learners

L1 and L2, from the demo data above, need to go into the real table first. Only then can any route read them back.

get_db() — One Session, Opened and Closed Around the Work

db.add_all stages both rows; db.commit() writes them for real.

You type 
from sqlalchemy.orm import sessionmaker

SessionLocal = sessionmaker(bind=engine)
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
db = next(get_db())
db.add_all([Learner(learner_id="L1", branch="Vesu", age=24, weekly_study_hours=9.3),
            Learner(learner_id="L2", branch="Citylight", age=27, weekly_study_hours=4.1)])
db.commit()
print(db.query(Learner).count())
Python shows 
2
  1. SessionLocal = sessionmaker(bind=engine) builds the factory, once, bound to the one engine.
  2. def get_db(): is the dependency a route will call through Depends().
  3. db = next(get_db()) runs get_db up to its yield, exactly like FastAPI does.
  4. db.commit() saves both staged rows to the database.
Tip: Call next(gen, None) after you finish with a session you opened by hand, so its finally block really runs and closes it.

3 — ➕ Create and Read Learners

A route needs a shape for the data it accepts before it can save anything. A Pydantic schema, as in Lesson 3, describes the fields a new record must have. The route turns that schema into a mapped row with Learner(**payload.model_dump()).

Reading one record by its key is the simplest query a session offers: db.get(Learner, learner_id) returns the row or None. Reading every record uses db.query(Learner).all(), which returns every mapped row as a Python list.

Call the create route before the read routes; a row has to exist before anything can find it.

🌟 Case Study: Adding and Finding Future Vision's Learners

Future Vision's admissions team wants to enrol a new learner, L3001 from Vesu, then look that learner up again.

@app.post("/learners") — Save a New Learner

Calling create_learner directly, with a session from get_db, shows exactly what FastAPI does for a real POST request.

You type 
from fastapi import FastAPI, Depends
from pydantic import BaseModel
app = FastAPI()
class LearnerIn(BaseModel):
    learner_id: str
    branch: str
    age: int
    weekly_study_hours: float
@app.post("/learners")
def create_learner(payload: LearnerIn, db=Depends(get_db)):
    db.add(Learner(**payload.model_dump()))
    db.commit()
    return payload
db = next(get_db())
new = LearnerIn(learner_id="L3001", branch="Vesu", age=22, weekly_study_hours=9.3)
print(create_learner(new, db))

4 — ✏️ Update and Delete a Learner

A PUT request replaces a whole record: the body you send becomes the new row, field for field. This differs from a form that only changes one box. Every required field must arrive, even the ones that are not changing.

Deleting removes a row for good. The route loads the record first, so a missing learner_id still gets a clear 404 instead of a silent no-op.

Load the record, check it exists, then act. That order keeps both routes from working on a learner that is not there.

🌟 Case Study: Moving L2 to the Pal Branch

L2 is transferring from Citylight to Pal, and later leaves the institute altogether.

@app.put("/learners/{learner_id}") — Overwrite Every Field

Each line copies one field from the request onto the stored row, so nothing keeps its old value by accident.

You type 
class LearnerUpdate(BaseModel):
    branch: str
    age: int
    weekly_study_hours: float
@app.put("/learners/{learner_id}")
def update_learner(learner_id: str, payload: LearnerUpdate, db=Depends(get_db)):
    learner = db.get(Learner, learner_id)
    if learner is None:
        raise HTTPException(status_code=404, detail="Learner not found")
    learner.branch = payload.branch
    learner.age = payload.age
    learner.weekly_study_hours = payload.weekly_study_hours
    db.commit()
    return learner.branch
db = next(get_db())
updated = LearnerUpdate(branch="Pal", age=28, weekly_study_hours=5.0)
print(update_learner("L2", updated, db))

  2. learner.branch = payload.branch overwrites the field directly on the mapped object.

A partial body like this is rejected before your route ever runs. Every field in LearnerUpdate is required, so FastAPI answers with status code 422, the same error from Lesson 4. The fix is simple: always send every field on a PUT.

5 — 🔍 Test Your API, Then Add Real Migrations

The docs page from Lesson 1 can run every route here, with no script to write. Each gets a Try it out form.

A real table keeps changing after launch: a new column, a renamed one. A migration is a small script that carries an existing table to its new shape, without losing its rows.

Alembic writes and runs these scripts. Base.metadata.create_all() only builds a table that does not exist yet, so a migration does the rest.

🌟 Case Study: Testing and Growing Future Vision's Learner API

Sections 1 to 4 now live in one file, ready to run.

You type 
from fastapi import FastAPI, Depends, HTTPException
from pydantic import BaseModel
from sqlalchemy import create_engine, String, Integer, Float
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, sessionmaker

engine = create_engine("sqlite:///./learners.db")

class Base(DeclarativeBase):
    pass

class Learner(Base):
    __tablename__ = "learners"
    learner_id: Mapped[str] = mapped_column(String, primary_key=True)
    branch: Mapped[str] = mapped_column(String)
    age: Mapped[int] = mapped_column(Integer)
    weekly_study_hours: Mapped[float] = mapped_column(Float)

Base.metadata.create_all(engine)
SessionLocal = sessionmaker(bind=engine)

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

class LearnerIn(BaseModel):
    learner_id: str
    branch: str
    age: int
    weekly_study_hours: float

class LearnerUpdate(BaseModel):
    branch: str
    age: int
    weekly_study_hours: float

app = FastAPI()

@app.post("/learners")
def create_learner(payload: LearnerIn, db=Depends(get_db)):
    db.add(Learner(**payload.model_dump()))
    db.commit()
    return payload

@app.get("/learners/{learner_id}")
def get_learner(learner_id: str, db=Depends(get_db)):
    learner = db.get(Learner, learner_id)
    if learner is None:
        raise HTTPException(status_code=404, detail="Learner not found")
    return learner.branch

@app.get("/learners")
def list_learners(db=Depends(get_db)):
    return [row.learner_id for row in db.query(Learner).all()]

@app.put("/learners/{learner_id}")
def update_learner(learner_id: str, payload: LearnerUpdate, db=Depends(get_db)):
    learner = db.get(Learner, learner_id)
    if learner is None:
        raise HTTPException(status_code=404, detail="Learner not found")
    learner.branch = payload.branch
    learner.age = payload.age
    learner.weekly_study_hours = payload.weekly_study_hours
    db.commit()
    return learner.branch

@app.delete("/learners/{learner_id}")
def delete_learner(learner_id: str, db=Depends(get_db)):
    learner = db.get(Learner, learner_id)
    if learner is None:
        raise HTTPException(status_code=404, detail="Learner not found")
    db.delete(learner)
    db.commit()
    return {"deleted": learner_id}

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="127.0.0.1", port=8000)

$ pip install alembic $ alembic init alembic $ alembic revision --autogenerate -m "add learners table" Generating alembic/versions/3f1a9c2b_add_learners_table.py ... done $ alembic upgrade head Running upgrade -> 3f1a9c2b, add learners table

alembic revision --autogenerate writes the script by comparing your models to the database. alembic upgrade head then runs it, keeping existing rows untouched.
